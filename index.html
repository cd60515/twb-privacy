TW Badminton Info 隱私權政策

Privacy Policy · 最後更新 Last updated: 2026-11-06

1. 這是什麼服務

TW Badminton Info 是應用程式擁有者個人使用的私人工具，用來整理台灣羽球零打／臨打資訊。此工具不對外開放註冊，沒有其他使用者，也沒有公開網站。

TW Badminton Info is a private tool used only by its owner to organize badminton pickup-game information in Taiwan. It has no public sign-up, no other users and no public website.

2. 透過 Threads API 存取的資料

  • 使用 Meta 官方 Threads API 的關鍵字搜尋，以「羽球 臨打」等關鍵字搜尋公開貼文。
  • 只保存：貼文前 140 字、發文時間、Threads 官方貼文連結（permalink）。
  • 不保存使用者名稱、個人檔案、相片、追蹤者或任何其他個人資料。
  • 只使用應用程式擁有者本人授權的存取權杖（access token），不代表任何其他使用者登入或操作。

The app uses the official Threads API keyword search for public posts (e.g. "badminton pickup"). It stores only the first 140 characters of the post text, the timestamp and the official permalink. It does not store usernames, profile data, images or followers. Only the owner's own access token is used.

3. 資料用途、分享與保存

  • 資料只供應用程式擁有者本人查看零打資訊，不公開、不出售、不分享給任何第三方，也不用於廣告。
  • 每筆資料最多保存 21 天，之後自動刪除。
  • 資料存放在私人的 GitHub 儲存庫，只有擁有者可存取。

Data is viewed only by the owner. It is never published, sold, shared with third parties or used for advertising. Each record is deleted automatically after 21 days. Data is kept in a private repository accessible only to the owner.

4. 刪除資料的方式

所有資料會在 21 天內自動刪除。如果你希望立即刪除與你的貼文相關的資料，請在 這裡建立 Issue 並附上貼文連結，我們會在 7 天內刪除並回覆。

All data is deleted automatically within 21 days. To request immediate deletion of data related to your post, open an issue here with the post link; it will be deleted within 7 days.

5. 聯絡方式

對本政策有任何問題，請透過 GitHub Issues 聯絡。

Contact: GitHub Issues.
